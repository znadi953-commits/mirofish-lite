# IN2PETA — Product Intelligence Seed
## Purpose
This document is a structured seed for MiroFish simulations about IN2PETA. It consolidates the supplied product, customer, pain-point, positioning, buyer, and service information. It should be treated as the factual seed supplied for the simulation; predictions and scenarios should be generated by the simulation rather than presented as established facts.

## 2. IN2PETA Coding Plan for Enterprises / Gateway
Type: B2B

Description:
Enterprise AI Coding + AI Gateway: a centralized layer for engineering teams to access multiple capable open-source coding models through pooled usage. The supplied material describes centralized logging and auditing, PII/PHI redaction, model routing, usage/cost visibility, multi-tenant support, and dedicated/in-house deployment options in a customer's AWS environment.

Ideal customer profile:
Startups and enterprises with 10–500+ developers/engineers using or evaluating Claude Code, Cursor, GitHub Copilot, OpenCode, Cline or similar AI coding tools. Strong-fit organizations include AI-first startups, SaaS companies, software product companies, fintech/healthtech/enterprise SaaS and teams with AWS credits or private/dedicated deployment requirements.

Pain signals:
- High AI spend
- Fragmented subscriptions and API keys
- Lack of audit logs
- Data privacy concerns
- PII/PHI exposure
- Need for centralized governance
- Model-provider lock-in
- Need for dedicated/private AI infrastructure

Key buyers/influencers:
CEO, CTO, VP Engineering, Head of Engineering, CIO, CISO, Head of AI/ML and Platform Engineering.

Key stated capabilities:
- Centralized AI access and governance
- Request/response logging for auditing and investigation
- PII/PHI redaction before data reaches models
- Routing across multiple open-source models
- Centralized usage, monitoring and cost visibility
- Multi-tenant support for teams, projects and organizations
- Pooled usage instead of fragmented per-developer subscriptions
- Multi-tenant deployment for pooled usage and potentially lower cost
- Dedicated deployment for greater isolation and control
- Dedicated/in-house deployment in the customer's AWS environment is described as an option

Important supplied positioning:
The material frames the opportunity as an AI control layer for an engineering organization, rather than merely cheaper AI coding. It contrasts fragmented per-developer subscriptions/API keys with centralized governance, auditable activity, privacy controls, multi-model routing and centralized usage/billing.

Cost claim in supplied material:
The supplied copy states that, with the right workloads, open-source models and optimized routing can potentially reduce inference costs by 10–20x versus proprietary-model-heavy setups. This is a claim in the seed, not an independently verified result.
