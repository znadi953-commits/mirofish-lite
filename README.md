# MiroFish Lite — LUXE DIGITAL Edition (SaaS)

Subscription product: **$4/month** (or $29/year). Landing page (`index.html`) sells the offer; `app.html` is the members-only simulator (access code delivered after subscription).

AI market-simulation in your browser. Bring your own (free) Gemini API key:
1. Open the site, pick provider **Google Gemini (free API key)**
2. Paste your key (get one free at https://aistudio.google.com/apikey)
3. Click the example **LUXE DIGITAL (16 ebooks)** or paste your own product document
4. Run — get a market-simulation report in 2-5 minutes

Your key stays in your browser and is sent only to Google. Nothing is stored on any server.

Based on [MiroFish Lite](https://github.com/sarcaxticlarka/mirrorfish_lite) (MIT).
